# Plugins

- `official/`: the plugins that ship with Omniscope (preloaded, removable). Maintained here.
- `community/`: plugins anyone can contribute with a pull request. Installed from **Settings → Get plugins**.
- `index.json`: the catalogue the app reads. It's generated by `python tools/build_index.py`, so don't edit it by hand.

How to write one: [docs/PLUGINS.md](../docs/PLUGINS.md).
